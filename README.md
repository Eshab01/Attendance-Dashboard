# Attendance Dashboard

## Overview
The **Attendance Dashboard** is a web-based application designed to track and display attendance data in a user-friendly interface. The dashboard provides real-time attendance monitoring, interactive elements, and a modern dark/light mode theme toggle for better usability.

## Features
- **Dark/Light Mode Toggle:** Seamless switching between dark and light themes.
- **Attendance Overview:** Displays the attendance percentage with a progress bar and message.
- **Profile Section:** Users can view and edit their profile details, including uploading a profile picture.
- **Navigation Menu:** Quick access to Dashboard, Reports, Settings, and Logout options.
- **Attendance Log:** Displays attendance records with filtering options and CSV download.
- **User Details Section:** Shows employee information and attendance statistics.
- **Interactive UI Elements:** Smooth transitions, hover effects, and animations for an engaging experience.

## Technologies Used
- **HTML5**: Structure of the webpage.
- **Tailwind CSS**: Provides responsive styling and UI components.
- **Font Awesome**: Icons for better UI interaction.
- **JavaScript**: Handles theme switching, UI animations, and dynamic content updates.
- **LocalStorage**: Saves theme preference for a persistent user experience.

## Installation & Setup
1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/attendance-dashboard.git
   ```
2. Navigate to the project directory:
   ```sh
   cd attendance-dashboard
   ```
3. Open `index.html` in a web browser.

## Usage
- Click the **theme toggle button** on the top right to switch between light and dark mode.
- Check attendance percentage and logs for real-time updates.
- Use the **filter option** in the attendance log to view specific dates.
- Download attendance reports with the **Download** button.
- Edit profile information using the **Edit Profile** button.

## Customization
- Modify the color themes in the `<style>` section inside `index.html`.
- Update attendance calculation logic in the JavaScript section.
- Extend the UI components using Tailwind CSS classes.

## Future Improvements
- Backend integration for dynamic data storage.
- User authentication system for secure access.
- Additional reporting and analytics for attendance trends.
